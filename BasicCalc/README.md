# AdvCalc - Advanced Professional Calculator

A feature-rich, professional calculator with multiple modes, unit converter, and extensive customization options.

## 🌟 Features

### 🧮 Multiple Calculator Modes
- **Standard Mode**: Basic arithmetic operations
- **Scientific Mode**: Advanced mathematical functions
- **Converter Mode**: Unit conversion for 8 categories
- **History Mode**: View and manage calculation history

### ⚙️ Comprehensive Settings
- **6 Beautiful Themes**: Light, Dark, Blue, Purple, Green, Orange
- **Sound Controls**: Toggle sounds, adjustable volume
- **Display Settings**: 
  - Thousands separator
  - Decimal places (0-8 or auto)
  - Scientific notation
  - Display animations
- **Calculator Behavior**:
  - Chain calculations
  - Auto decimal
  - Angle units (Degrees/Radians/Gradians)
- **History Management**: Save and limit history
- **Advanced Settings**: Performance modes, button animations

### 🔧 Advanced Features
- **Memory Functions**: MC, MR, M+, M-
- **Scientific Functions**:
  - Trigonometric (sin, cos, tan, inverses)
  - Logarithmic (log, ln, log2, exp)
  - Advanced (factorial, absolute, round, random, etc.)
- **Unit Converter**:
  - Length, Weight, Temperature, Area, Volume
  - Time, Speed, Data Storage
- **Calculation History**: 20+ item storage with timestamps
- **Keyboard Support**: Full keyboard shortcuts

### 🎨 Professional Design
- Modern glass-morphism design
- Smooth animations and transitions
- Responsive layout for all devices
- Accessible color schemes
- Professional typography

## 🚀 Quick Start

1. **Open `index.html`** in any modern browser
2. **Basic Usage**:
   - Click numbers and operators
   - Press `=` or Enter to calculate
   - Use `AC` to clear all, `CE` to clear entry
3. **Switch Modes**: Click tabs at the top
4. **Access Settings**: Click gear icon (☰) in top-right
5. **Unit Converter**: 
   - Select conversion type
   - Enter value and select units
   - Click "Use in Calculator"
